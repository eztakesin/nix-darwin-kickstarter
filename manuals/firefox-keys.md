# Firefox 无标签栏操作速查(macOS)

标签栏被 `userChrome.css` 隐藏了(见 `dotfiles/firefox/userChrome.css`),
标签依然存在,只是看不见——全部靠键盘操作。

## 最重要的两个

| 操作 | 快捷键 |
| --- | --- |
| **按名字找标签页**(替代"用眼睛找") | `⌘L` 然后输入 `%` + 关键词 |
| 在标签间循环 | `⌃Tab` / `⌃⇧Tab` |

`%` 是地址栏的**「只搜已打开的标签页」**前缀。看不见标签栏之后,这是找回某个
标签最快的方式:`⌘L` → `% github` → 回车,直接跳过去(而不是新开一个)。

地址栏其他前缀,顺带记住:

| 前缀 | 搜索范围 |
| --- | --- |
| `%` | 已打开的标签页 |
| `*` | 书签 |
| `^` | 历史记录 |
| `#` | 匹配标题 |
| `$` | 匹配网址 |

## 标签基本操作

| 操作 | 快捷键 |
| --- | --- |
| 新建标签 | `⌘T` |
| 关闭当前标签 | `⌘W` |
| **恢复刚关掉的标签** | `⌘⇧T`(可连按,一路撤销) |
| 下一个 / 上一个标签 | `⌃Tab` / `⌃⇧Tab` |
| 同上(另一组) | `⌘⌥→` / `⌘⌥←` |
| 跳到第 1–8 个标签 | `⌘1` … `⌘8` |
| 跳到**最后一个**标签 | `⌘9` |
| 新窗口 / 隐私窗口 | `⌘N` / `⌘⇧P` |
| 关闭窗口 | `⌘⇧W` |

## 可选:让 ⌃Tab 按「最近使用」顺序切换

默认 `⌃Tab` 按标签的**排列顺序**走。改成像 `⌘Tab` 那样按**最近使用**顺序
(并弹出预览面板),在标签不可见时更好用——想加就在
`dotfiles/firefox/user-overrides.js` 里加一行:

```js
user_pref("browser.ctrlTab.sortByRecentlyUsed", true);
```

## 万一界面出了问题

`userChrome.css` 改坏了导致界面不可用时,不必进 profile 目录抢救——
把 `user-overrides.js` 里这行改成 `false` 再 switch 即可整体停用:

```js
user_pref("toolkit.legacyUserProfileCustomizations.stylesheets", true);
```

### 红黄绿按钮位置不对?

`userChrome.css` 里 `#nav-bar { padding-left: 76px }` 是给窗口按钮腾的位置。
盖住了「后退」就调大,留白太多就调小。

如果按钮**整个消失**,说明这版 Firefox 不再把它们画到 nav-bar 上——那就在
`user-overrides.js` 里加 `user_pref("browser.tabs.inTitlebar", 0);`,
Firefox 会改用原生标题栏(会多出一条系统标题栏,但按钮回来了)。
